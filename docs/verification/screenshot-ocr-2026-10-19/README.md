# 截图工具栏 OCR（2026-10-19）

完成标准：工具栏可直接识别当前选区；沿用设置里的模型配置；结果显示在选区旁边并可选择、滚动、复制；等待时界面可操作；取消、失败、超时和重试有反馈；深浅色、小屏与全屏选区不遮挡工具栏；原有保存、复制和贴图功能正常。

已完成：
- 截图、白板截图、衣架图片标注入口均传入同一份文字识别配置。
- 新增 OCR 按钮，发送前保留图片上传确认，只发送当前选区的最终图片。
- 识别在后台执行，防止重复发送。结果以纯文字显示，支持滚动、选择、复制和重新识别。
- 面板优先摆放到右侧，其次左侧、下方、上方。全屏和小屏使用屏内浮动位置，避开工具栏。
- 修改图片、标注或选区后收起旧结果；识别中关闭截图不会访问已关闭的窗口。
- 按用户对 macOS 样式的要求，使用系统字体、清楚的文字层级、无边框阅读区、轻量关闭按钮、主次按钮、细分隔线和柔和阴影。补充处理了应用主题与系统外观不一致时的按钮配色。
