# 设置精简与按键录入验收（2026-10-19）

完成标准：快捷键可以直接按键录入，不强制修饰键；录入 Enter、Esc、Tab 不误保存、关闭或切换焦点；保存重开保留绑定，应用内实际使用生效；设置不显示关闭功能的细项；原有检查通过。

本次调整：
- 移除识别和翻译的“等待上限”设置控件，沿用已有等待策略及旧配置。
- 圆角、边框、触发角关闭时收起细项，重开保留原值。
- 全局快捷键与标注快捷键改为按键录入；标注快捷键提供禁用按钮。
- 全局支持无修饰键的字母、数字、F1–F20、空格、Tab、Enter、Esc、退格、删除、插入、导航和常见符号键；纯修饰键与媒体键暂不支持。
- 设置窗口打开期间暂停应用自身的全局快捷键，保存或取消后恢复。
- 标注自定义绑定优先于同键固定操作；macOS 按实际 Control / Command 区分。
- 补充 macOS、Windows、X11 和 Wayland 的新增键映射；Windows、Linux 未进行系统实测。
