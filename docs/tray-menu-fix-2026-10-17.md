# 托盘菜单点击修复（2026-10-17）

## 本次变更

- macOS 托盘入口改为由 QSystemTrayIcon 的 activated 信号弹出 Qt 菜单，不再同时绑定原生 contextMenu。左、右键激活均支持；保留其他平台的既有托盘入口。
- 托盘动作排队执行，避开菜单点击派发期间的 clear()、重建和打开窗口。弹出菜单期间暂停触发角，防止抢走操作。
- 衣架勾选读取实际启用状态。启动时即使关闭衣架，也保留可重新启用的实例；同步支持 Wayland 启停分支，但本次未运行 Linux 验证。
- 失败提示改为应用内可见窗口，避免系统通知被隐藏后操作没有反馈；平台能力也改为显式显示并激活的窗口。
- 保留开始工作前已有的衣架、贴图菜单修改。
