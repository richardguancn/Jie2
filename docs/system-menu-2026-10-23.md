# macOS 系统菜单

主菜单、暂存图片菜单、贴图右键菜单和截图工具菜单改用 macOS 自带菜单。
背景、圆角、选中效果、字体和深浅色均由系统负责，未加入自定义背景或菜单行视图。

保留现有文案、勾选状态、子菜单、提示、图标及有效快捷键。菜单关闭后执行对应操作，避免重建菜单或打开窗口时打断菜单选择。菜单打开期间暂停角落截图。

## 验证

- 构建和应用启动检查通过。
- 真实 macOS 桌面下 `systemMenus` 检查通过：确认打开的是系统菜单，菜单行没有自定义视图；验证点击、勾选、禁用、子菜单和取消。
- 从菜单栏入口打开菜单、切换图片暂存、切换圆角、暂存图片操作、贴图旋转以及截图工具切换均通过。
- 非 macOS 及无桌面测试使用既有菜单路径。

此前文案检查保存的菜单图片仅作排版参考，不代表切换后的系统背景效果。
