# J2 界面文案

名称用 2–4 字，说明不超过 20 字。快捷键、文件名、服务地址和识别结果按实际内容显示。
同一功能在菜单、设置和提示中使用一致的名称。删除、发送内容和保存密钥的提示保留实际后果。

## 主菜单

| 名称 | 说明 |
| --- | --- |
| 截图 | 拖动鼠标，选择要截取的区域 |
| 贴到屏幕 | 把已复制的图片、文字或颜色贴在屏幕上 |
| 提取文字 | 提取已复制图片中的文字 |
| 翻译内容 | 翻译已复制的文字或图片 |
| 扫码 | 读取已复制图片中的二维码或条形码 |
| 最近截图 | 在子菜单中查看最近保存的文件名 |
| 截图外观 | 圆角、边框、阴影 |
| 角落截图 | 在所选角落停留后截图 |
| 图片暂存 | 鼠标停在屏幕顶部，查看暂存图片 |
| 自动收集 | 自动暂存复制的图片 |
| 设置 | 调整使用习惯和连接服务 |
| 功能检查 | 查看当前能使用的功能 |
| 退出应用 | 退出 J2 |

有屏幕贴图时，显示“全部显示”或“全部隐藏”、“全部保存”、“贴图分组”和“全部关闭”。
截图和贴图的有效快捷键显示在右侧，符号键显示对应符号。

## 设置分类

| 分类 | 说明 |
| --- | --- |
| 常规 | 按你的习惯，设置截图与图片暂存。 |
| 截图标注 | 设置图片外观和标注工具。 |
| 屏幕贴图 | 把已复制的内容贴在屏幕上。 |
| 快捷键 | 点击输入框，再按下要使用的按键。 |
| 提取文字 | 提取图片中的文字，完成后自动复制。 |
| 翻译内容 | 翻译已复制的文字或图片。 |

常规设置使用“颜色模式”“图片暂存”“复制图片”“系统截图”“角落截图”“截图位置”“停留时间”。
截图标注使用“圆角”“圆角半径”“边框”“边框宽度”“边框颜色”“阴影”“颜色数量”“直接擦除”。“直接擦除”的说明为“擦除后不能撤销”。
贴图按键使用“关闭贴图”“隐藏贴图”“配合按键”。快捷键按“随时可用”和“标注工具”分组，“保存图片”说明保存的是已复制的图片。
连接服务保留服务方实际使用的“服务地址”“模型名称”“服务密钥”，并说明应填写服务方提供的内容。翻译设置使用“翻译语言”。

## 图片与贴图菜单

暂存图片使用“复制”“打开”“标注”“显示文件”“存到桌面”。自己的截图使用“删除图片”，并说明会移到废纸篓；外部图片使用“移出暂存”，并说明保留原文件。

屏幕贴图使用“还原”“复制图片”“另存图片”“窗口阴影”“调整图片”“粘贴”“替换图片”“移到分组”“显示文件”“隐藏贴图”“关闭贴图”“缩放大小”。
图片调整使用“向左旋转”“向右旋转”“左右翻转”“上下翻转”“反转颜色”。旋转提示保留 90°，缩放提示保留原图尺寸。

## 操作提示

发送前明确显示“发送图片”或“发送内容”，列出实际接收服务，默认选择“取消”。
密钥提示为“密钥在本机保存，未加密。”及“请勿分享设置文件。”
完成提示统一使用“截图完成”“保存完成”“复制完成”“翻译完成”。读取、打开、保存和识别失败时，说明具体问题，不把未发现写成不存在。
