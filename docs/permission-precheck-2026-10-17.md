# 2026-10-17 macOS 权限提示误报

## 本次已确认事实

用户明确反馈：已开启授权，且能够截取其他应用，只是“平台能力”仍提示未授权。

只读查询 macOS 系统日志后，发现当前安装应用 `/Applications/jie2.app`、标识 `app.jie2.desktop`、当时运行进程 7281 的屏幕录制请求被系统判为 `Allowed (System Set)`。该记录对应当前安装程序的身份。不能把本次现象归因为“用户未授权”或直接断言为旧签名授权失效。

进一步使用同一份已安装应用执行实际抓屏，返回成功，输出 `/tmp/jie2-permission-verification/capture.png`，尺寸 3420×2214。图片本轮仅核对输出与尺寸，其他应用内容可被截取这一点由用户反馈确认。检查后重新启动同一份程序，文件摘要保持不变，没有重新签名、替换安装应用、修改系统授权或重置授权记录。

## 修正

- macOS 的 `CGPreflightScreenCaptureAccess()` 返回否定时，状态改为待确认，不能据此直接写成“未授予屏幕录制权限”。
- 提示明确区分预检查与实际抓屏：能正常截图时无需重复授权；仅在截图失败时检查系统设置。
- 删除辅助功能未授权就无法窗口吸附的错误说明；现有窗口边界吸附通过窗口列表实现，并未以辅助功能授权作为前提。
- 系统未返回截图时，不再把预检查的否定结果直接当作失败原因。

上述修正已在工作区构建，未替换用户当前已授权的安装应用或重新生成安装包。当前用户使用的应用已实际确认能正常截图。
