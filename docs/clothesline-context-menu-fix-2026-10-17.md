# 衣架右键菜单点击修复

用户反馈衣架卡片菜单的复制、打开、标注、在访达中显示、保存到桌面和丢弃均无反应。

衣架与贴图窗口曾将 `QMenu::toNSMenu()` 直接交给 AppKit 弹出，绕过 QMenu 自身的弹出与动作处理流程。本次统一使用 `QMenu::exec()`，使菜单的显示、点击分发、取消和销毁由同一套流程管理。macOS 上菜单外观改为 Qt 菜单。

新增七组交互回归：右击真实衣架卡片，实际向弹出的菜单发送鼠标点击，分别检查六项信号只发出一次且图片路径正确；另检查 Esc 取消不触发动作。测试不直接调用 QAction::trigger()，不依赖调用菜单构造函数替代实际右键入口。

验证结果：

- macOS 桌面运行七组菜单交互检查与已有贴图菜单检查，共 10 项通过（含初始化和清理）。菜单预览已查看。
- 全量 CTest 两组检查通过。
- 本次交互回归验证到衣架动作请求的发出，未逐项启动外部看图程序、访达，也未向用户桌面写入图片或删除用户截图。
- 安装包位于 `dist/context-menu-fix-2026-10-17/`，未替换已安装的应用。
- DMG 和 ZIP 完整性检查通过；ZIP 解压后应用签名检查通过，包内程序可输出版本号。
