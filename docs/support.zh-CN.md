# JTwo 使用支持

JTwo（应用内简称 J2）是截图、标注和屏幕贴图工具。启动后可从菜单栏打开截图、设置和其他操作。

## 首次使用

1. 启动应用，从菜单栏选择截图。
2. 如果 macOS 要求录屏权限，前往系统设置中的“隐私与安全”允许 J2 录屏。
3. 按屏幕提示框选区域，再进行标注、保存或复制；具体按键可在设置中查看和修改。

## 常见问题

- **截图中看不到其他应用**：检查 macOS 录屏权限；根据系统提示退出并重新打开应用后再试。
- **快捷键没有反应**：在设置中换用未被系统或其他软件占用的组合。
- **文字识别或翻译不可用**：这些在线功能需要自行配置支持相应能力的服务地址、模型和密钥；基本截图和标注不需要这些设置。第三方服务可能另行收费。
- **商店版没有自动读取系统截图或按钮识别**：商店版遵循系统权限限制，支持本应用截图、窗口吸附、标注、贴图及复制图片暂存。
