# 2026-10-16 界面与交互对齐

本轮针对现有实现中的具体差距做增补，不代表两个参照产品的全部界面和操作已逐项完成实机对照。

## 对照依据

- Snipaste 本地评估基线：项目《截2-可行性评估报告.md》1.5、1.8 节；[官方操作说明](https://docs.snipaste.com/zh-cn/getting-started)。
- Tendedero [官方说明](https://github.com/alejandrobujan/tendedero)与 [GrabArea.swift](https://github.com/alejandrobujan/tendedero/blob/main/Sources/Tendedero/GrabArea.swift)：单击复制、双击打开、长按 0.45 秒标注、右键菜单，以及拖动时区分复制与移动。

## 本轮变化

- 截图工具条从长文字按钮改为统一线条图标，保留名称提示、当前工具高亮和不可撤销时的禁用状态。工具条靠选区右侧排列，空间不足自动换行，底部空间不足则移到上方，并为尺寸标签留位。
- 操作提示在窄窗口换行；尺寸与起点标签限制在屏幕内，数值按图片本身计算。指针进入工具条时收起放大镜，双击工具按钮不会确认截图。
- 衣架增加双击打开、长按标注和右键菜单。取下操作明确保留原文件。菜单展开或拖动期间保持衣架展开。
- 长按、松手、拖动、隐藏与历史更新相互取消未完成的手势，避免误复制或误打开标注器。
- 衣架标注直接选中整张图；完成后另存并复制，取消不保存。保存新图时不重复应用截图装饰或尺寸设置，也不复用命令行指定的输出路径。
- 拖动载荷使用原图，缩略图仅用于拖动时的外观。
